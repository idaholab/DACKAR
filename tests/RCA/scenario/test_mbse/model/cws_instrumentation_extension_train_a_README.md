# CWS Instrumentation Extension Package

Files:
- `cws_instrumentation_extension_train_a_patch.json`
- `cws_pilot_model_v3_1_instrumented_train_a.json`

This package adds a Pump Train A instrumentation extension to the clean CWS baseline.

Included:
- discharge flow transmitter
- discharge pressure transmitter
- motor breaker status source
- pump run status source
- monitoring boundary
- definition-level and usage-level signal connectors
- new signal flows and functions

Use the merged model directly for validation, or apply the patch in your own ingestion pipeline.
