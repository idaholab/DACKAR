src.dackar.RCA.cmms_integration.sap_pm_cmms_adapter¶

sap_pm_cmms_adapter — SAPPMCMMSAdapter skeleton.

Implements CMMSContextAdapter for SAP Plant Maintenance using the SAP OData API (PM Maintenance Notifications / Orders). Plant teams fill in the connection details and field mappings. See CMMS_INTEGRATION_GUIDE.md §4 for the full implementation guide.

Dependencies (not installed by default):

pip install requests

class src.dackar.RCA.cmms_integration.sap_pm_cmms_adapter.SAPPMCMMSAdapter(base_url, username, password, plant=None, notification_endpoint=_DEFAULT_NOTIFICATION_ENDPOINT, order_endpoint=_DEFAULT_ORDER_ENDPOINT, timeout=30)[source]¶

Live SAP PM adapter — fetches Maintenance Notifications (CRs) and Maintenance Orders (WOs) via the SAP OData API.

Parameters:

  • base_url (str) – SAP system base URL, e.g. "https://sap.plant.corp".

  • username (str) – SAP user name (basic auth).

  • password (str) – SAP password (basic auth). Consider using a service account with read-only PM authorisations.

  • plant (Optional[str]) – SAP plant code (e.g. "1000").

  • notification_endpoint (str) – OData path for maintenance notifications.

  • order_endpoint (str) – OData path for maintenance orders.

  • timeout (int) – HTTP request timeout in seconds.
