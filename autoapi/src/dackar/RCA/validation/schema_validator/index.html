class src.dackar.RCA.validation.schema_validator.RCAArtifactValidator(schema_dir, *, mode='compat')[source]¶
Two-layer validator:

  1. per-artifact Draft7 JSON Schema validation

  2. cross-artifact semantic consistency checks

Modes:

  • strict: no legacy field aliases; schema mismatches are errors

  • compat: normalize common legacy aliases before validation

  • warn_only: same checks, but schema/semantic failures downgraded to warnings

Parameters:

  • schema_dir (str | pathlib.Path)

  • mode (Literal['strict', 'compat', 'warn_only'])

validate_artifact(artifact_type, payload)[source]¶

Validate a single artifact payload against its schema and semantics.

The payload is first normalized (a deep copy — the caller’s payload is never mutated) and validated against its Draft 7 schema. Semantic consistency checks run only when schema validation passes: those checks assume schema-valid object types, so running them on malformed input could raise instead of reporting an issue.

Parameters:

  • artifact_type (str) – One of CORE_ARTIFACTS. Whitespace and case are normalized.

  • payload (Dict[str, Any]) – The artifact object to validate.

Returns:

All findings for this artifact. An unknown artifact_type yields a single schema_missing issue. This method does not raise on invalid payloads — every problem is returned as a ValidationIssue.

Return type:

Validate a run bundle: each member individually, then cross-artifact.

Every supplied member is validated on its own via validate_artifact(), then the schema-valid members are checked for cross-artifact consistency (shared event_id / asset_id, evidence and candidate cross-references, full-mode RCA-card requirements, etc.).

Parameters:

  • event (Optional[Dict[str, Any]]) – Keyword-only bundle members. Each is optional; a member left as None is skipped entirely. Caller payloads are never mutated.

  • telemetry_summary (Optional[Dict[str, Any]]) – Keyword-only bundle members. Each is optional; a member left as None is skipped entirely. Caller payloads are never mutated.

static _parse_instant(value)[source]¶

Parse an ISO-8601 date-time string into a timezone-aware datetime.

Returns None when the value is not a parseable string, so callers skip the comparison rather than raising. A naive datetime (no offset) is assumed to be UTC, so two timestamps are always compared as instants and offsets like +01:00 vs Z order chronologically, not lexicographically.
