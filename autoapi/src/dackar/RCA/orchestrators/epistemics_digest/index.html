src.dackar.RCA.orchestrators.epistemics_digest._classification_resolution_level(meta)[source]¶

How the epistemic class was determined for this hit.

Prefers the explicit classification_resolution_level written upstream by doc_extraction (finding_status / authority_level / doc_type / default); only when that provenance is absent does it fall back to inferring the level locally.

src.dackar.RCA.orchestrators.epistemics_digest._is_degraded(meta)[source]¶

Whether this hit’s epistemic classification is degraded.

Prefers the explicit degraded_classification flag written upstream by doc_extraction; only when that flag is absent does it fall back to treating a hit with no epistemic_class annotation as degraded.
