src.dackar.outage.stages.stage_g_recommendation¶

Stage G — Recommendation Synthesizer.

Responsibilities:

  1. Select the primary recommendation from InsertionOptions.

  2. Determine the decision_status (PROCEED / DEFER / ESCALATE / MONITOR / INCONCLUSIVE).

  3. Build the executive_summary (plain-language conclusion, confidence tier, analyst attention flags).

  4. Assemble the evidence chain from upstream artifacts — every claim must cite a source (WBS 11.2 traceability requirement).

  5. Surface all regulatory flags from Stage A.

  6. Build schedule and history summaries for the executive view.

  7. Set analyst_review=True when required (regulatory constraints present, low confidence, INCONCLUSIVE status, upstream fallback used, or unknown abbreviation rate > threshold).

  8. Compute the validation_status block.

Output schema: outage/schemas/outage_activity_recommendation.json

Design principle (from critical_analysis.md §8):
Every recommendation must surface:

  1. the specific historical outages it draws from

  2. the number of analogous events in the training data

  3. an explicit confidence tier

  4. a reject-with-reason path that feeds back into the learning loop

Reuse targets:
RCA.synthesis.rca_synthesizer_v31 → evidence selection pattern, confidence

tier logic, fallback detection

RCA.validation.schema_validator → _compute_validation_status()

_select_primary_option(insertion_options)[source]¶

Retrieve the recommended option object from InsertionOptions.

Looks up insertion_options[‘recommended_option_id’] in the options list and RE-VERIFIES it is both feasible and regulatory-cleared before returning it (B5). A pre-computed insertion_options bundle could point recommended_option_id at a regulatory-blocked or infeasible option; trusting it blindly produced e.g. a DEFER on a regulatory-blocked defer. Missing feasible/regulatory_cleared default to False (fail closed), not True. Returns None (→ INCONCLUSIVE) when no valid option is found.

_determine_decision_status(primary_option, intake_result, historical_analogs, insertion_options, schedule_impact_assessment=None)[source]¶

Map the primary option and context to a decision_status enum value.

Logic (evaluated in priority order):
INCONCLUSIVE — primary_option is None (no feasible, regulatory-cleared

option exists)

ESCALATE — primary option type is escalate_to_management DEFER — primary option type is defer_to_post_outage ESCALATE — FAIL-CLOSED GATE (outage.policy.is_fail_closed): any

non-defer/non-escalate option escalates when an LCO clock is expired/critical/urgent/unknown, a regulatory constraint is present, or CP impact could not be computed (cp_impact_unavailable). PROCEED/MONITOR are not permitted in those cases.

MONITOR — low confidence + no historical analogues + activity

is non-critical path (watch, but no action yet warranted)

PROCEED — primary option type is insert_now / contingency /

parallel / scope_reduction / pre_outage_staging

schedule_impact_assessment (N5 fix): criticality_label is read from schedule_impact_assessment["float_analysis"]["criticality_label"] (not the non-existent insertion_options["schedule_summary"]). It is optional; when absent, criticality falls back to non_critical for the MONITOR check and cp_impact_unavailable reads as False.

_compute_attention_flags(intake_result, historical_analogs, schedule_impact, temporal_chain, insertion_options)[source]¶

Compute the list of analyst attention flags.

Each flag is a string constant defined at module level. Flags are raised when:

_FLAG_REGULATORY — intake_result.has_regulatory_constraint _FLAG_LOW_CONFIDENCE — confidence_tier == ‘low_confidence’ _FLAG_LOW_ANALOGS — analog_count < config.min_analog_count_for_no_flag _FLAG_TEMPORAL_CONTRADICTION — temporal_chain.summary.has_temporal_contradiction _FLAG_CP_IMPACT — schedule_impact.float_analysis.criticality_label == “critical” _FLAG_HIGH_ABBR_RATE — intake_result.unknown_abbreviation_rate > threshold _FLAG_FALLBACK — historical_analogs.retrieval_summary.fallback_used _FLAG_DISPLACED_REGULATORY — any displaced task has has_regulatory_constraint=True _FLAG_LCO_EXPIRED — intake_result.lco_clock_status == “expired” _FLAG_LCO_CLOCK_CRITICAL — lco_clock_status in {“critical”, “urgent”, “unknown”}

and active LCO is present

_assemble_evidence_chain(temporal_event_chain, historical_analogs, schedule_impact, component_event_timeline, intake_result=None)[source]¶

Build the evidence chain for the recommendation.

Each entry cites one specific piece of supporting evidence. Sources in priority order:

  1. regulatory_constraint — inserted at position 0 when intake_result.has_regulatory_constraint is True (N6 fix: the max_evidence_items cap must never displace a regulatory entry; anchoring it first guarantees it survives truncation)

  2. temporal_chain_link — strongest Allen relation link(s)

  3. historical_analog — top-similarity analogs with duration data

  4. schedule_analysis — CP drag / float analysis result

  5. condition_report — highest-DQ CR from the component timeline

Each entry: evidence_id, source_type, source_id, snippet, relevance_score, supports.

Mirrors _summarize_primary_evidence() from the RCA orchestrator but operates on outage artifact types (read-only reuse pattern).

_determine_analyst_review(decision_status, intake_result, historical_analogs, insertion_options, attention_flags)[source]¶

Determine whether analyst review is required before acting.

required=True when any of:

  • has_regulatory_constraint is True

  • lco_clock_status is fail-closed (expired/critical/urgent/unknown)

  • _FLAG_CP_IMPACT in attention_flags (critical-path impact)

  • _FLAG_CP_UNAVAILABLE in attention_flags (CP impact not computable)

  • _FLAG_DISPLACED_REGULATORY in attention_flags

  • _FLAG_TEMPORAL_CONTRADICTION in attention_flags

  • decision_status is INCONCLUSIVE

  • duration distribution confidence_tier is low_confidence

  • _FLAG_FALLBACK is in attention_flags

  • _FLAG_HIGH_ABBR_RATE is in attention_flags (§6 exit criterion: NER entity extraction unreliable when unknown_abbreviation_rate exceeds RecommendationConfig.unknown_abbreviation_rate_warning)

  • no feasible + regulatory-cleared option exists (fail-closed defaults)

reason: brief string summarising why review is required. reviewer_decision initialised to None (populated by the analyst UI).

_compute_validation_status(evidence_chain, regulatory_flags, historical_analogs)[source]¶

Compute the validation_status block.

schema_valid: always True here (schema validation runs

in the orchestrator’s _validate_and_persist).

all_regulatory_flags_resolved: fail-closed. When any regulatory flag is

present this is False at generation time — a regulatory constraint is resolved only by a human acknowledgement, which does not exist yet in Stage G output (analyst_review.reviewer_decision is still None; it is populated later by the analyst UI). True only when there are no flags.

minimum_evidence_met: True if len(evidence_chain) >= 1 with at

least one supports=True entry.
