class src.dackar.outage.outage_uncertainty.retrieval.similarity_engine.SimilarityAggregator(weights=None)[source]¶

Bases: dackar.similarity.scoreAggregator.WeightedScoreAggregator

Combine the outage similarity dimensions into a single total score.

A thin outage adapter over dackar.similarity.scoreAggregator.WeightedScoreAggregator that pins the four retrieval dimensions (lexical / semantic / context / dependency) and keeps the keyword-style combine() signature the engine calls.

Parameters:

weights (dict[str, float] | None) – {dimension: weight} dict. The default ships with "dependency": 0.0 so the aggregator is backwards compatible when no dependency scorer is wired. Pass a non-zero "dependency" weight together with a DependencyPatternScorer to activate the schedule-neighbourhood component (Gap 4).

Default weights (dependency disabled):

lexical: 0.20,  semantic: 0.40,  context: 0.40,  dependency: 0.00
combine(lexical, semantic, context, *, dependency=0.0)[source]¶

Return the weighted combination of per-dimension scores, clamped to [0, 1].

The dependency parameter is keyword-only so existing call sites that pass only the three positional-style keyword arguments continue to work without modification.

Clamping to [0, 1] (inherited from the base aggregator) matters here: without it, unnormalized weight dicts (weights summing to > 1) would produce total scores above 1.0, which would inflate NeighborSelector power weights quadratically and let any moderate match trivially pass ConfidenceEstimator’s best-match threshold.

Parameters:

  • semantic (float)

  • context (float)
