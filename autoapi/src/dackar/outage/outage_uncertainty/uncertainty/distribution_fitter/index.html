src.dackar.outage.outage_uncertainty.uncertainty.distribution_fitter¶

Empirical distribution fitter with weighted percentile support.

Weighted percentiles¶

Each duration in the routine group carries a relevance_weight assigned by NeighborSelector. High-similarity neighbours receive proportionally more weight, so the P50/P80 estimate is dominated by the closest historical analogs rather than treating all matches as equally informative.

Algorithm (weighted Hazen / midpoint percentile)

  1. Sort (duration, weight) pairs by duration.

  2. Build a weighted CDF placing each point at its midpoint position (cumulative_weight_before + 0.5 * weight) / total.

  3. Interpolate linearly between adjacent points to find the value at quantile q.

With uniform weights this reduces to NumPy’s Hazen percentile (np.percentile(..., method="hazen")), i.e. plotting position (i + 0.5) / n — not the default linear/Type-7 method. For uniform 1..10 this gives P90 = 9.5 and P10 = 1.5 (vs 9.1 / 1.9 for Type-7); the midpoint convention is deliberate so the tail quantiles are not pulled inward by the small historical-analog samples typical here.

fit_from_separation(separation)[source]¶

Fit a two-component mixture distribution from an OutlierSeparation.

The routine group drives the primary percentile estimates (p10 … p90). When an extended group is also present:

  • dist.extended_samples and dist.mixture_weight are populated so that sample(), mean(), and variance() reflect the full mixture.

  • Mixture-aware p80 / p90 (combining both pools with their respective mixture weights) are stored under parameters["mixture_p80"] / "mixture_p90"] for planners who want a single tail quantile that accounts for disrupted executions.

Compute the q-th weighted percentile of values.

Uses linear interpolation between adjacent CDF points placed at midpoint positions (cumulative_before + 0.5 * w) / total. With uniform weights this is NumPy’s Hazen percentile (method="hazen"), not the default Type-7 method.
