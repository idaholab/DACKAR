class src.dackar.outage.outage_uncertainty.domain.duration.DurationDistribution[source]¶

Empirical duration distribution, optionally representing a two-component mixture of routine and disruption-driven execution modes.

distribution_type[source]¶

"empirical" for similarity-fitted distributions; "fallback_constant" when only planned duration is available.

parameters[source]¶

Metadata dict: extended_fraction, n_routine, mixture_p80, mixture_p90, etc. Populated by DistributionFitter.

samples[source]¶

Routine-pool durations (sorted ascending). Used for clean-execution percentile interpretation.

extended_samples[source]¶

Disruption-driven durations separated by OutlierHandler. None when no outliers were detected.

mixture_weight[source]¶

Probability of disrupted execution (= extended_fraction from separation). When 0, the distribution is purely routine.

p10 / p50 / p80 / p90

Weighted percentiles of the routine pool. Mixture-aware percentiles are stored under parameters["mixture_p80"] / "mixture_p90".

sample(n=1)[source]¶

Draw n samples from the distribution.

When extended_samples is populated and mixture_weight > 0, each draw is taken from the disruption-driven pool with probability mixture_weight and from the routine pool otherwise. This produces realistic heavy-tailed samples for downstream Monte Carlo simulation.

Parameters:

n (int)

Return type:

list[float]

mean()[source]¶

Mixture mean: (1 - w) * E[routine] + w * E[extended].

Return type:

float

variance()[source]¶

Mixture variance via the law of total variance.

Var(X) = E[Var(X|Z)] + Var(E[X|Z])

where Z is the mixture component indicator (0 = routine, 1 = extended). When no extended pool is present this reduces to the routine sample variance.

Return type:

float
