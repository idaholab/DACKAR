class src.dackar.outage.outage_uncertainty.adapters.pandas_repository.PandasActivityRepository[source]¶

Build ActivityCase objects from plain dict rows.

The rows typically come from DataFrame.to_dict("records"), so missing cells arrive as float('nan') rather than None. Values are coerced through the shared _to_float / _to_str / _to_bool helpers so a missing numeric field becomes None (not nan) and a missing string becomes None (not the literal "None"); otherwise nan would pass the is not None filters downstream and surface as p50=nan.
