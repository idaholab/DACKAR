src.dackar.similarity.OllamaEmbedder¶

Ollama-backed dense-vector text embedder.

A stateless (except for its cache) embedder served by a locally running Ollama instance. The same instance can be shared across callers.

Embedding model notes:

  • nomic-embed-text:latest — fast, 274 MB. Good general-purpose default.

  • mxbai-embed-large:latest — stronger retrieval ranking, ~2.4x larger (669 MB).

Caching¶

Two-level cache:

  1. In-memory — a plain dict mapping text to embedding, living for the lifetime of the embedder instance. Avoids redundant API calls within a single run.

  2. Persistent JSON file (optional) — loaded at construction and saved on demand via save_cache(), so embeddings survive across restarts.

Graceful degradation¶

If the Ollama server is unreachable (URLError, TimeoutError) the embedder logs a warning and returns a single-element vector [0.0] so the caller can fall back (e.g. to a lexical similarity measure).

Only the standard library is required.

Parameters:

  • model (str) – Ollama model name, e.g. "nomic-embed-text:latest" or "mxbai-embed-large:latest".

  • base_url (str) – Base URL of the Ollama HTTP API. Default "http://localhost:11434".

  • cache_path (str | None) – Optional path to a JSON file used as a persistent cache. If the file already exists its contents are loaded on construction. Call save_cache() to flush in-memory additions back to disk.

  • timeout (int) – HTTP request timeout in seconds. Default 30.
