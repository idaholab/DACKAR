loader¶

Load RCA artifact bundles from a full-result JSON file or a fixtures directory.

Run the Streamlit app from this directory so import loader resolves:

cd DACKAR/src/dackar/RCA/viz && streamlit run app.py

loader.load_from_fixtures_dir(directory)[source]¶

Merge every *.json in a directory into one bundle, keyed by filename.

The directory may be a hand-built fixtures folder or a real orchestrator run folder (ArtifactStore writes one <artifact_name>.json per artifact), so scanning the directory surfaces whatever artifacts are actually present rather than a fixed allow-list. _FIXTURE_FILE_MAP is consulted as an alias layer: a basename it names maps to that key, otherwise the filename stem is the key. Missing files are simply absent; never raises for them.

Parameters:

directory (str)

Return type:

JsonDict

loader.merge_bundles(primary, supplemental)[source]¶

Return primary with any keys it lacks filled in from supplemental.

Primary wins on every shared key, so a complete run bundle is never overwritten; the supplement only contributes artifacts the primary is missing (e.g. the raw event / telemetry_summary inputs that a v32_full_result.json does not carry, or the generated artifacts a hand-built fixtures folder lacks). This lets one view combine the data provided as input with the data produced by every pipeline stage.
