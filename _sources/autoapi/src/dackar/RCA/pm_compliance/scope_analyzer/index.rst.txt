.. py:function:: analyze_scope(kg_context, checks)

   Build per-component scope view.

   :returns: * *components_out* -- Per-component list with ``scope_covers_failure_modes``, ``scope_gaps``.
             * *linkage_flag* -- True when the KG carries explicit PM↔FM tags.
             * *covered_fms* -- FM IDs covered by at least one passing check.
             * *all_fms* -- All FM IDs present in the KG.
             * *check_to_coverage_type* -- Maps check_id → ``"preventive"`` | ``"detective"`` for every check whose
               task ID appears in a KG FM linkage field.  Empty when linkage is absent.
               Used by the aggregator to set ``pm_tasks[].coverage_type``.
