.. py:class:: SpanConsolidatorPolicy

   Policy knobs for candidate consolidation.

   v0.1 defaults:
     - Dedupe identical spans (same start/end)
     - Keep nested spans
     - Do not do aggressive partial-overlap pruning yet


   .. py:attribute:: dedupe_identical_spans
      :type:  bool
      :value: True



   .. py:attribute:: keep_nested_spans
      :type:  bool
      :value: True



   .. py:attribute:: prefer_longest_on_overlap
      :type:  bool
      :value: False



.. py:class:: SpanConsolidator(policy = None)

   Consolidates raw candidates into a cleaner set.

   Responsibilities:
     - Merge duplicates across generators (same offsets)
     - Union provenance sources and label hypotheses
     - Optional overlap pruning policies (kept minimal for v0.1)


   .. py:attribute:: policy


   .. py:method:: consolidate(doc, candidates)
